# Manual para trabajar

El día a día, en un Mac. Si es la primera vez que os ponéis en este repo, pasad antes
por `INSTALACION.md`: se hace una vez y deja todo listo.

---

## 1 · Ubicarse en la carpeta del repo

Al abrir el terminal estaréis en vuestra carpeta personal, que se escribe `~`
(*home*). Con `ls` veis qué carpetas tenéis a la vista, y con `cd` entráis en la que
os interesa:

```bash
ls
cd MISYKS-Beta
```

El prompt se actualiza y pasa a mostrar la ubicación nueva: donde antes decía `~`,
ahora dice `~/MISYKS-Beta`. El formato exacto depende de cómo tengáis configurado el
terminal, pero la parte de la ruta es la que os dice dónde estáis.
